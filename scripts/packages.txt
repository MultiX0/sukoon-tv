# Packages debloat.sh turns off on any Android TV or Google TV, with "pm disable-user" (never uninstalled, so
# restore.sh brings them back). Packages your TV doesn't have are skipped. One package per line; text after # is a
# note. Extras for one model go in devices/<model>.txt (the model as `adb shell getprop ro.product.model` prints it,
# spaces replaced by underscores).
#
# Never add: anything for inputs/HDMI, the tuner, CEC, picture and sound, the remote (com.google.android.tv.remote.service
# carries the mic on some remotes), TCL's com.tcl.suspension (Inputs button), Hisense smartsense packages, Philips
# org.droidtv.*, com.droidlogic.* / com.mediatek.* / com.realtek.* system services. See the README's device table.
